32-битное ядро для x86, написанное на C и ассемблере.

## Реализовано
- Загрузка через Multiboot, загрузка в `kernel_main`
- GDT, IDT, ремап PIC
- Прерывания клавиатуры (IRQ1)
- Терминал в текстовом режиме VGA с мини-шеллом внутри ядра (`help`, `clear`)
- Менеджер физической памяти: buddy-аллокатор
- Страничная адресация (VMM)
- `kmalloc` / `kfree`: slab-аллокатор (от 32 Б до 2 КБ)

## Требования
- Кросс-компилятор `i686-elf-gcc` (GCC для цели i686-elf)
- `nasm`
- `grub-mkrescue` (вместе с `xorriso` и `mtools`)
- `qemu-system-i386`

## Сборка и запуск
    make        # собрать бинарник ядра
    make iso    # собрать загрузочный ISO-образ
    make run    # собрать ISO и запустить в QEMU
    make clean  # удалить файлы сборки
